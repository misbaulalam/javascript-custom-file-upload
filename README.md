# javascript-custom-file-upload

A simple JavaScript project that creates a **custom file upload button** and displays the selected file name. This project demonstrates DOM manipulation and handling file input events in a browser.

## 🚀 Features
- Click a custom button to open the file picker
- Display the selected file name on the button
- Pure HTML, CSS, and JavaScript
- Lightweight and beginner-friendly

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (DOM & Events)

## 📂 How to Use
Clone the repository.
